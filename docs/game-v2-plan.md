# 《醒来之前》独立叙事游戏执行计划

Goal：完整可玩的独立电脑游戏原型，包含成熟的视觉重点与完整叙事闭环；不能把这次交付描述为已经过公开发行测试的商业成品。

用户已选择独立电脑游戏，并授权必要软件下载。正式舞台的姥爷仍是真人，电脑游戏中的形体为该演出的数字化预演角色。

## 设计约束

故事目标是让人认出自己的举动被照顾。没有分数/排行榜，不将音量或动作总次数当成情感成功。先保留清楚的动作-反馈关系，再让变化延迟回响。沉默、轻动作和暂停均要能完成故事。

使用Godot 4.7.2 Compatibility/OpenGL3.3，已在本机Intel Iris Xe实际运行。工作目录 `game/`，旧 `prototype/` 保留为对照。正式舞台投影/传感器/升降台尚未接入，真人群体体验也尚未验证。

## 验收

从入口到结尾不需开发者操作台；角色不会穿过主要实体；至少两种参与方式能走完；交互提示与视觉焦点相符；自己的动作可在结尾明确辨认；游戏可暂停和重玩。关键资产在正面/侧面/玩家距离下均可读，实时效果不依赖离线渲染截图冒充。
