# 美术与玩法验收：v0.2

视觉方向：手工记忆剧场。材质温柔、有使用痕迹，轮廓克制；保持黑色无边空间、朱红窗、青绿石板和太阳雨。明亮窗景应托住姥爷与小熊，不吞掉手部动作。

重点资产：两只熊共享同一母版，具有一侧略歪的耳朵、奶油色口鼻、砖红织物、左袖修补线；能单独处理耳、脸、袖与手接触点。人物避免机器人球形关节，采用衣服覆盖的连续肩背、弯曲手臂、可读侧脸和银发。作为数字预演角色，不声称复刻真实姥爷肖像。

纹理：物体自己的UV/PBR纹理；不再使用随摄像机变化的石材条纹。石板有厚度、细层理和磨圆边；红窗有木质构造、内外框层次、淡旧漆；熊的毛绒用细表面纹理和少量轮廓细节表现，不依赖大规模实时毛发。

核心交互：微小试探立即有局部回声；连续变化让人理解关系；照顾段保留玩家此前动作的类型与节奏。所有手势都有安静替代，不以反复喊叫解锁剧情。观察、走近和停留是行动。

游戏流程：开场菜单→黑暗探索/呼喊→首次共振→太阳雨与自由动作→走近产生空间退远→发现交换区→放下小熊/抱起大熊→姥爷回应此前动作→安静结尾→重玩。

视角验收：玩家常态1.55m视线、近看熊、左侧看照顾、右侧看照顾、全景。正式舞台另需实际投影与演员遮挡测试。不得仅用一张离线渲染证明实时效果完成。

可玩验收：WASD/鼠标，碰撞，E上下文交互，明确但少量提示，暂停/恢复/重玩/音量/视角灵敏度；无法走出空间或撞进桌椅。没有开发控制台才能完成的关键步骤。
