# 醒来之前 · 独立叙事游戏 v0.2

进入黑暗，抱着一只小熊，试着让一个停住的下午重新动起来。

## 玩游戏

双击交付包中的 **BeforeWaking-v0.2.exe**。游戏不需要安装Godot或Blender，主流程离线可玩。

点击“进入这个下午”。你可以自由走动和试探，不需要开启后台或切章节。开场的呼喊不会叫醒他；踏地、抱熊、哼唱或整理袖口会留下痕迹。走近后，房间会退远；左侧出现大熊时，走过去按E交换。转身看看姥爷，让照顾发生，再按E结束。

| 操作 | 按键 |
|---|---|
| 行走 / 快走 | WASD / Shift |
| 看向四周 | 鼠标；左右方向键也可转身 |
| 看向姥爷 | R |
| 踏地 / 抱住小熊 | 空格 / 按住F |
| 哼唱 / 理顺左袖 / 呼喊 | H / J / Q |
| 上下文交互 | E |
| 暂停、声音、灵敏度、步行起伏、重玩 | Esc 或 P |

抱熊是一条完整的安静路径，不要求大喊。声音目前是合成的临时声景与字幕，没有人物配音。鼠标会被游戏捕获，Esc可以释放。

## 演员与AI后台

F8打开排练后台。单人游戏的常规路径使用本场实际动作、时间和位置完成规则回调。

如果同机运行旧版 `prototype` 中的 `npm run dev`，游戏可以连接 `http://127.0.0.1:4173` 的AI服务。凭证仍只在该服务器环境里；Windows交付包没有API密钥。AI只在操作员点击“准备AI动作提议”时调用，可以接纳或拒绝；换段后迟到建议丢弃。没有该服务，完整游戏照常运行。

玩家做过的动作和AI建议的回应方式分别保存，AI不会把“踏步”改写成玩家曾经“哼唱”。当前数字动画只执行预设动作类别，AI文字中的细微动作仍需真人演绎。

## 开发与资产

锁定Godot **4.7.2 stable**，使用Compatibility/OpenGL渲染；Blender母版为 **4.5.3**。打开 `project.godot` 即可编辑。当前电脑可从项目根目录运行：

```powershell
& '.tools/godot/4.7.2/Godot_v4.7.2-stable_win64_console.exe' --path game
```

- `assets/room.glb`、`bear.glb`、`grandpa.glb` 为游戏资产。
- `source/before-waking-art.blend` 为含打包贴图的可编辑母版。
- `source/build_art.py` 和 `make_textures.py` 可重建原始网格、纹理和临时声音。source目录被Godot忽略，避免运行依赖Blender安装。
- `scripts/story.gd` 负责叙事状态、真实动作与回调来源；`player.gd` 负责碰撞移动；`game.gd` 负责世界、UI和后台。
- `tests/story_test.gd` 是行为验证；`-- --qa=quiet`、`warm`、`collision`、`ai` 为明确标记的自动试玩。AI测试会调用已配置的服务。

运行状态测试：

```powershell
& '.tools/godot/4.7.2/Godot_v4.7.2-stable_win64_console.exe' --headless --path game --script res://tests/story_test.gd
```

使用 `export_presets.cfg` 导出Windows可执行文件。预设引用项目 `.tools` 中经过校验的官方Windows导出模板；换机需安装匹配模板或更新其路径。

游戏结束时只把最近一场的匿名动作记录写到Godot用户数据目录下的 `last-dream.json`，不上传。重玩覆盖这份记录；它不是云端账号或跨人身份识别。

## 本版实际边界

本版是完整可玩的短篇原型，不是已经经过公开发行测试的商业游戏。它使用键盘和鼠标模拟身体参与，目前为单人体验。正式舞台中的姥爷仍由真人扮演；电脑里的形体用于数字预演，不是亲人肖像复刻。

模型、PBR纹理、角色移动、碰撞、空间反馈、交换、结尾和后台已落地；手臂使用两段关节解算，让托抱和摸脸目标跟随小熊，手指仍为固定造型。穿衣是预设动作与衣物显现，尚未采用真实布料模拟。太阳雨、金线和云景是实时效果；没有咖啡瀑布、实际传感器、投影机或升降台接入。

能认出动作来源的程度、故事是否动人、多人共同在场的效果，仍需新玩家与真人演员试演，不能用通过测试或截图替代。
