# 醒来之前 · 共振排练室 v0.1

这是一份可运行、可改变路径的舞台预演。正式演出的姥爷由真人扮演；屏幕中的形体只帮助检查站位、转身和熊的交接。

## 打开

在本目录运行 `npm run dev`，打开 http://127.0.0.1:4173 。也可以在 PowerShell 运行 `./start.ps1`。当前机器已经安装依赖；换电脑需先装 Node.js 22+，再运行 `npm ci`。

点击“进入这个下午”，然后选择“热烈一场 · 90s”或“安静一场 · 90s”即可看完整模拟演绎。播放不是预渲染视频：六个段落的舞台与效果始终实时绘制。90秒用于快速检查结构，不代表正式演出时长。

## 自己排练

1. 选 A–D；1–4 也可切换。先呼喊，房间没有回答。踏步或其他身体动作开始金光，累计六个非呼喊动作唤起房间。
2. 空格踏步、W 摇摆、S 哼唱、H 抱熊、J 理袖、C 呼喊。雨的密度、风向、彩虹和金线随输入改变。四人的贡献分别记录。
3. 后续按“下一节拍”推进。追赶段按“向他靠近”，只移动数字房间。交换段必须先“交换小熊”，再进入照顾。
4. 在观察栏选择动作类型、写下具体细节，例如“先拉平左袖，停一拍，再拍两下手背”。记录归到当前选中的人。
5. 选“真实 AI”→“准备一条共振提议”。演员可以接纳或拒绝。AI不能直接换场；接纳后重现该人的光线与照顾动作类别，具体表演细节交给真人。
6. HOLD 冻结演出和输入；它会停止自动模拟，恢复后由演员继续。底部六个标签用于跳段检查，会令旧提议失效。“重新开始”清空本场。

“沉浸观看”收起控制台并降低视线；拖动和滚轮可以查看侧面。“舞台布局”显示固定演员、数字窗景、交换区和四个输入区。

独立输入页：`/?audience=A`，B/C/D 同理。现在用同一台电脑的多个标签页测试，服务器只监听本机。尚未开放手机局域网接入，也没有摄像头或可穿戴识别。只开一个主舞台标签页，其他参与者用独立输入页。

## AI 与规则的分工

- 规则负责即时视听反馈、六个叙事段落和暂停逻辑。AI等待不会卡住舞台。
- 真正的 OpenAI Responses API 在服务器端调用。默认模型 `gpt-4.1-mini`；可以通过 `STAGE_AI_MODEL` 更换。凭证从服务器环境变量 `OPENAI_API_KEY` 读取，不写入源码或浏览器。
- 每条提议必须指向真实的事件 ID 和参与者；段落版本变化后自动丢弃。服务器只发送最后24条匿名动作及操作员备注，设置 `store:false`；这不代表对服务商其他保留政策作承诺。
- 无凭证时仍可完整排练。“规则对照”和两个90秒模拟明确采用规则，不伪装成AI。
- AI的视觉建议是给设计师的文字建议；当前渲染器只执行经过编码的局部金线和四类照顾动作，不会把任意文本变成任意舞台效果。
- 事件按人归因是已实现能力；“每个人都感到独一无二”“演员因此更动人”仍待真人试演验证。

## 可继续制作的资产

`public/assets/before-waking-master.blend` 是 Blender 4.5.3 生成的可编辑母版；`before-waking-stage.glb` 是运行资产。红窗、青绿石板桌椅、大小熊、衣物和人物占位均有独立对象。

资产生成源：`scripts/build_assets.py`。当前机器从项目根目录运行 `.tools/blender-env/Scripts/python.exe prototype/scripts/build_assets.py` 可重建；`.tools` 未纳入版本管理。标准 Blender 中也可运行该脚本。

`src/score.js` 保存独立事件及段落模型；`src/stage.js` 实时绘制；`src/audio.js` 是程序合成的临时声景；`server.mjs` 负责AI和多人输入。`npm run check` 运行行为测试，`npm run build` 进行构建校验。实际运行仍用 `npm run dev`，单独打开 dist 不包含AI服务。

## 本版边界与下一次排练

这一版是轻量 Three.js 预演与 Blender 资产交付，没有原生 Unreal 工程。它未连接投影机、真实升降台或动作传感器；熊的交换、穿衣是走位与显露占位，尚非手指接触与布料动画。它也没有证明多人裸眼视差、现场亮度与演员遮挡已经解决。窗景目前为程序云雨，尚未实现咖啡瀑布等额外魔法片段。

下一次最有价值的试演：一名姥爷演员、一名引导演员、四位参与者，两只小熊与一把椅子。操作员记录动作；分别演规则与AI两场，检查参与者能否说出“后面那个动作回应的是我的哪一下”，同时观察演员是否需要等待、是否还能自主处理沉默。记录认出来源的人数、认错次数、等待和人工覆盖次数；不把音量大小当作情感成功。

先用这次真人试演选择有效动作和时机，再把实时画面迁入专业工作站。迁移约定见 `../docs/stage-control-contract.md`。
